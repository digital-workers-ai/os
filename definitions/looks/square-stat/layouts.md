# `square-stat` — frames

One proof point, 1080×1080, in the console's own tokens: `#F5F3EB` ground,
`#FFFFFF` card, `#E0DCC1` hairline, `#FD4E00` for the number alone.

## card

```
┌──────────────────────────────┐
│ ┌──────────────────────────┐ │
│ │                          │ │
│ │  29                      │ │  stat, 324px, brand orange
│ │  competitor ads still    │ │  label, 50px, ink
│ │  running                 │ │
│ │                          │ │
│ │  Four of them have been  │ │  support, 31px, muted
│ │  live since March.       │ │
│ │  ────────────────────    │ │  hairline
│ │  ● DIGITAL WORKERS       │ │  mark, 26px, tracked
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

The number is the only thing in the accent, so a card with two orange things on
it has one thing too many. `support` is the sentence that makes the number mean
something; without it the card is a figure nobody asked for.

Draft renders the ground flat. Build may replace it with a generated image, and
the card sits on top of it unchanged — the copy is always HTML, never pixels.
