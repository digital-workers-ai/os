# Language

## Names

- DW-OS is the product. Always "DW-OS": never "DWOS", "DW OS", "the OS" or "Dw-os".
- Digital Workers is the company. Two words, both capitalised. Never "DW" alone in copy.
- The console is for whoever operates it. The dashboard is for whoever runs the business.
- The nightly agent is the AI engineer that proposes issues. Never "the bot".
- A rebuild is the step that turns the raw store into everything above it.
- The definition files: ontology, mappings, transforms, synonyms, derived, metrics, rules, goals, dashboards, enrichment.
- Tool names are written as their makers write them: HubSpot, Customer.io, WooCommerce, Google Ads.

## Words to use

- tool, record, field, number, target, finding
- kept as it arrived, rebuilt, traced, reviewed
- a person approves, a person merges, a person confirms or rejects
- which tool, which records, which were missing the field
- open source, AGPL-3.0, on your own machine
- off by default, needs its own key
- definition file, mapping line, review queue

## Words to avoid

- AI-powered, intelligent, smart, magic, autonomous
- single source of truth, 360-degree view, unified
- seamless, effortless, instantly, real-time
- insights, unlock, leverage, empower, supercharge
- revolutionary, game-changing, next-generation
- guarantee, always accurate, never wrong
- pipeline, ETL, data warehouse: say rebuild, raw store, definitions

## Numbers and names

- A number appears only when proof.md lists it, exactly as listed.
- Never name a customer, a person, or a private company.
- Never promise a date, or a feature the README lists as future.
- "Small business" and "small company" are the reader; never "SMB".
