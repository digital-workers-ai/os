Four pillars. Every asset leads with one of them and does not try to carry all
four at once. The lines under each are the ones that have earned their place.

## 1. Numbers with receipts

Every number says where it came from.

- Which tool, which records, and which of them were missing the field.
- Nothing here is a black box.
- The same data gives the same answer, every time.
- When a number can't be measured, it says so instead of guessing.

## 2. Your business as code you own

The operating logic is plain files your company owns and versions.

- What a customer is, how revenue is calculated, what counts as a problem.
- Change the definition and there is a before, an after, a reviewer and a date.
- When a number moves, you can tell whether the business moved or the
  definition did.
- The files disagree, the system refuses to start, and it names the file.

## 3. One picture from every tool

Sales has one Acme, billing has another, support has a third.

- 29 tools connected, joined on what actually identifies a customer.
- Records that look alike but might not be go to a person, not a guess.
- Raw data kept as it arrived, everything rebuilt from it.

## 4. An engineer in your loop

An AI agent works the system every night and hands you the fixes.

- It reads what changed, finds what is drifting, writes up the evidence.
- It opens an issue. It never commits and never approves itself.
- You approve, a second agent builds it, a person merges it.

## Positioning against the alternatives

Against a dashboard: a dashboard shows the number. This one can defend it.

Against a data team: the same discipline, without the headcount.

Against doing nothing: the spreadsheet is already wrong, and nobody knows
which cell.

## The one-liner

An AI operating system for small businesses, built as code your company owns
and evolves.
